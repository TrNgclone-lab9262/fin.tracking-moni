# 🚀 UNIVERSAL NEXT.JS 14 STARTER TEMPLATE
> **Cấu hình thiết kế:** Calm Professional Fintech & Precise Terminal (`--preset b2dJCEImFF`)  
> **Đặc trưng:** Bo góc vi mô 2px (`rounded-[2px]`), Tone màu Deep Navy & Slate, phối hợp Rose nữ tính trang nhã cho Bé Mèo / gia đình.

---

## 📦 Công Nghệ Tích Hợp Sẵn
- **Framework:** Next.js 14 App Router
- **Ngôn ngữ:** TypeScript 5
- **Styling:** Tailwind CSS 3.4 + `tailwindcss-animate`
- **UI Components Primitives:** shadcn/ui (style `default`), `@radix-ui/react-slot`, `class-variance-authority` (cva), `clsx`, `tailwind-merge`
- **Icons:** Lucide React
- **Linting:** ESLint 8 (`eslint-config-next@14.2.18`)

## ⚡ Hướng Dẫn Sử Dụng Để Bắt Đầu Dự Án Mới (Chỉ 30 Giây)

### Cách 1: Copy toàn bộ thư mục sang dự án mới
1. Sao chép toàn bộ thư mục `templates/next-starter-template` sang thư mục dự án mới của bạn:
   ```bash
   cp -r templates/next-starter-template ../ten-du-an-moi
   cd ../ten-du-an-moi
   ```
2. Cài đặt các gói phụ thuộc:
   ```bash
   npm install
   ```
3. Chạy môi trường phát triển:
   ```bash
   npm run dev
   ```
4. Mở trình duyệt tại `http://localhost:3000` để bắt đầu code ngay!
